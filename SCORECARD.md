# Agent-Readiness Scorecard

## 1 · Score each layer

Score from the **bottom up**. A layer can only be trusted at a given score if every layer beneath it is already ≥2.

| Layer | The agent's question | Your score (0–3) | Evidence / notes |
| --- | --- | :---: | --- |
| **5 · Leverage** | Can I capture value and learn? | ☐ | |
| **4 · Trust** | Can the transaction be trusted? | ☐ | |
| **3 · Transactability** | Can an agent actually buy? | ☐ | |
| **2 · Comprehension** | Can it understand what I sell? | ☐ | |
| **1 · Presence** | Can an agent find and reach me at all? | ☐ | |

**Scale:** `0` Absent · `1` Basic (present but unreliable) · `2` Functional (works end-to-end for a competent agent) · `3` Optimized (works *and* agents prefer you over a comparable merchant).

> Tip: if you're unsure between two scores, take the lower one. Agent-readiness is graded by the agent that fails, not the demo that succeeds.
